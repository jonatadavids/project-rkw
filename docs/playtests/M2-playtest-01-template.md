# M2-T20 — Checkpoint: validação do vertical slice com pilotos reais

## Como usar este template

`tasks.md` (M2-T20) exige distribuir o build para **ao menos 2 pilotos reais
de kart** (além do fundador), coletar feedback qualitativo e uma nota 0-10
por critério, e documentar o resultado aqui — copie este arquivo para
`docs/playtests/M2-playtest-01.md` e preencha uma cópia da tabela abaixo por
piloto. Critério de conclusão de M2-T20: **média ≥ 6/10, nenhum critério
abaixo de 5, aprovação qualitativa de ao menos 2 pilotos**.

O build atual (`./scripts/build_deploy_verify.sh`) já passou por várias
rodadas de ajuste guiadas pelo fundador — ver `docs/30-founder-playtest-log.md`
para o histórico técnico. Este checkpoint é sobre pessoas que **não**
participaram desse ajuste testando o resultado com olhos frescos.
